🧠 Console-Based Quiz Game

Test your knowledge with this interactive Python quiz game

About This Project

This is a stylish and interactive quiz game built with Python that runs in the console/terminal. Test your knowledge across multiple categories with a visually appealing interface featuring colors, emojis, and smooth animations.

Created by Saurabh Patil as part of an educational project demonstrating Python programming skills.

🎮 Key Features

📚 Multiple Categories

Questions in Python, General Knowledge, Technology, and Science

🎚️ Difficulty Levels

Easy, Medium, and Hard questions with different point values (10/20/30 points)

🤖 Adaptive Mode

Game automatically adjusts question difficulty based on your performance

⏱️ Timer Functionality

Time limits per question (15/12/10 seconds) with bonus points for quick answers

🏆 Enhanced Scoring

Streak bonuses, time bonuses, and penalties for wrong answers

📊 Player Statistics

Track your performance over time with detailed statistics

▶️ How to Run the Game

To play this quiz game, you'll need to clone the repository and run it locally:

Method 1: Direct Execution

  1. Make sure you have Python installed (version 3.6 or higher)
  2. Clone or download the repository
  3. Navigate to the project directory in your terminal/command prompt
  4. Run the game with:
python main.py

Method 2: Installation (Recommended)

  1. Clone or download the repository
  2. Navigate to the project directory
  3. Install the package:
pip install .

Then run the game from anywhere:

quiz-game

🎯 How to Play

  1. Enter your name when prompted
  2. Select a category (or choose "All Categories" for mixed questions)
  3. Choose a difficulty level:
    • Easy: 10 points per question, 15 seconds per question
    • Medium: 20 points per question, 12 seconds per question
    • Hard: 30 points per question, 10 seconds per question
    • Adaptive: Automatically adjusts based on your performance
  4. Answer each question before time runs out by entering A, B, C, or D
  5. Earn bonus points for quick answers and streaks
  6. See your score at the end with a performance evaluation
  7. View the high scores leaderboard or your personal statistics
  8. Choose to play again or exit
